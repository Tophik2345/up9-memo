# Памятка УП-9

Статический сайт для игрового проекта Russia Online. HTML, CSS и JavaScript; без зависимостей и сервера.

Откройте index.html или разместите каталог на GitHub Pages. Для пересборки: node redesign.mjs. Генератор использует оригинальные поля body из content.json, а не прежние форумные редакции.

11 тем, 36 исходных подразделов, общий поиск, ссылки на подразделы, мобильный выбор подраздела. При отключённом JavaScript все материалы остаются доступны.

Источник — предоставленная пользователем памятка. Статьи о территориях воспроизведены из неё и не отмечены как подтверждённые форумом.
