# Памятка Управления «9» — Russia Online

Статический справочный сайт для сотрудников Управления «9» ФСБ РО в игровом проекте Russia Online. Семь страниц, все 36 разделов исходной памятки, поиск по всему тексту и 13 тематических быстрых ответов. Это игровая нормативная база; текст не дополняется законодательством реальной РФ.

## Файлы

- `index.html` — главная, быстрый доступ, компетенция.
- `service-check.html` — служебная проверка и объяснения.
- `operative-check.html` — оперативная проверка и ОРМ.
- `powers.html` — базы, документы, территории и принуждение.
- `discipline.html` — взыскания и отстранение.
- `crime-sk.html` — преступление и Следственный комитет.
- `algorithm.html` — последовательность из восьми шагов.
- `style.css`, `app.js` — оформление и интерактивные функции.
- `data.js` — поисковый индекс и быстрые ответы, создаётся сборкой.
- `content.json` — структурированная копия 36 разделов для сверки, создаётся сборкой.
- `memo.txt` — полный исходный текст памятки, основной источник.
- `build.mjs` — генератор страниц без сторонних зависимостей.
- `favicon.svg`, `.nojekyll` — значок и настройка статической публикации.

## Локальный запуск

Можно просто открыть `index.html` в браузере: поиск работает и без сервера. Для локального сервера при установленном Python: `python -m http.server 8000` из папки проекта, затем открыть `http://localhost:8000`. Node.js нужен только для обновления сгенерированных страниц: `node build.mjs`.

## GitHub Pages

Загрузить содержимое этой папки в отдельный репозиторий `up9-memo`. В Settings → Pages выбрать Deploy from a branch, ветку `main`, папку `/ (root)` и Save. После успешной публикации адрес: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/up9-memo/`.

Платные сервисы, база данных и backend не нужны. Все пути относительные: сайт работает в подпапке GitHub Pages. Каждая страница — настоящий HTML-файл, поэтому прямые ссылки и перезагрузка работают без перенаправлений. Текст и аккордеоны доступны без JavaScript; поиск и быстрые ответы требуют JavaScript.

## Как обновлять памятку

Редактировать соответствующий номерной блок в `memo.txt`, сохраняя разделители из дефисов. Затем запустить `node build.mjs`. Генератор переносит весь текст блоков, выделяет основания, условия и запреты. Проверить обновлённую страницу и поиск. Не редактировать только `data.js` или `content.json`: при следующей сборке они перезаписываются.

Краткие названия, статусные метки, быстрые ответы и распределение по страницам находятся в `build.mjs` (`titles`, `labels`, `introductions`, `answers`, `route`). При изменении нормы обновлять также связанный быстрый ответ. Все ответы должны оставаться основанными на памятке.

Для добавления статьи: добавить номерной блок в `memo.txt`, его заголовок в `titles`, при необходимости изменить распределение `route` и ожидаемое количество разделов в проверке генератора и подписи поиска. Сохранять существующие номера: они используются в прямых ссылках `#section-N`. Для новой страницы добавить её в `pages`, назначить ей статьи в `route` и пересобрать. Навигация появится автоматически. Алгоритм использует раздел 36; его особую обработку менять отдельно при перенумерации.

## Поиск и быстрые ответы

Поиск локально проверяет названия, исходные заголовки, полный текст, НПА, номера статей и тематические ключевые слова всех 36 разделов. Регистр, «ё/е» и пунктуация нормализуются; для длинных слов используется простое сопоставление основы. Все слова запроса должны совпасть, номера проверяются отдельно от соседних цифр. Результат открывает страницу и нужный раскрытый блок. Например: `ст. 66`, `ст. 77`, `ст. 35`, `Discord`, `КПЗ`.

«Быстрый ответ» сопоставляет вопрос с заранее составленными тематическими карточками. Это не ИИ и не источник новых полномочий. Неизвестный вопрос предлагает воспользоваться полным поиском.

## Оформление карточек

Метки описывают условие или смысл конкретной темы, а не объявляют общий запрет. Короткие вступления в `introductions` согласованы с заголовками; генератор проверяет, что заменяемый фрагмент совпадает с исходником. Поле `body` сохраняет исходный текст, `displayBody` — текст карточки для отображения и результатов поиска. При изменении начала раздела в `memo.txt` обновить соответствующий `introductions`. Цветовое выделение запрета не переносится на следующие самостоятельные абзацы.
