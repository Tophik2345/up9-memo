# Памятка УП-9

Сайт: https://tophik2345.github.io/up9-memo/

Статический игровой справочник Russia Online, Кутузовский. 11 тем, 36 подразделов, поиск и мобильная версия.

## Проверка оснований — 25.09.2026

Непосредственно открыты пять тем официального форума. Индекс zakon-RO-/kutuzovsky.json использован для поиска ссылок, а не вместо первоисточника.

Проверено 26 уникальных статей: 23 подтверждены, 3 не найдены. Оформление 23 подтверждённых ссылок уточнено: полные названия НПА, названия статей, части/пункты и главы Кодекса. Повторы одной статьи в разных карточках не считаются отдельными основаниями.

Не подтверждены статьи 2.7, 2.18 и 3.16 из прежнего названия закона о территориях (КПЗ/допросные, закрытые территории, режимные объекты). Старая ссылка перенаправляет на «О государственных территориях РО», где этих номеров нет. Они отмечены для проверки, а не заменены похожими статьями. Исходные утверждения сохранены только в явно помеченных подробностях.

LEGAL-AUDIT.json содержит список статей, источники и соответствие подразделам. legal-bases.mjs — единый проверенный справочник для отображения. source-memo.json сохраняет исходную памятку: это архив, не подтверждение её ссылок.

Сборка: node redesign.mjs. HTML, CSS, JavaScript, без зависимостей. Не использовать прежний build.mjs для пересборки новой версии.
